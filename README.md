# Hey, I'm Lucas 👋

Self-taught full-stack developer from Argentina 🇦🇷, building software for 8+ years.
I work across the whole stack, from the database to the last pixel, mostly with .NET and
TypeScript. I care about code that's easy to read and UI that's easy to use.

Lately I've been building small tools that make working with AI coding agents nicer,
plus whatever side project scratches the itch of the week.

### What I'm building

- **[Croessant](https://github.com/lucaslobasso/croessant)**: the fastest way to issue ARCA
  invoices (Factura C) from your desktop. Electron, Linux / macOS / Windows.
- **[wait-gotta-tune](https://github.com/lucaslobasso/wait-gotta-tune)**: a simple chromatic
  tuner for web, Android and iOS. Expo / React Native.
- **Claude Code tools**: small mods and utilities I use every day:
  [launcher](https://github.com/lucaslobasso/claude-launcher) ·
  [taskbar](https://github.com/lucaslobasso/claude-taskbar) ·
  [statusline](https://github.com/lucaslobasso/claude-statusline) ·
  [limit-revive](https://github.com/lucaslobasso/claude-limit-revive) ·
  [boxed-messages](https://github.com/lucaslobasso/claude-boxed-messages) ·
  [language-spinner](https://github.com/lucaslobasso/claude-language-spinner)
- **[personal-dashboard](https://github.com/lucaslobasso/personal-dashboard)**: a static hub
  over my own data repos, served from GitHub Pages.
